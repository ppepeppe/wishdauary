# wish 다유어리 UI 기준

## 토큰

`src/index.css`가 유일한 디자인 토큰 원본이다. 화면별 색상·간격·모서리 값을 추가하기 전에 기존 토큰을 사용한다.

- 색상: `brand`는 주요 동작의 연핑크 배경, `brand-on`은 그 위의 글자, `brand-ink`는 링크·선택 상태에 쓴다. 초록은 클로버·성공, 빨강은 오류·삭제에만 쓴다.
- 글자: 본문 `text-base` 16px, 보조 정보 `text-xs` 13px, 최소 보조 글자 `text-2xs` 12px, 페이지 제목 `text-xl` 24px. 입력값은 16px로 유지한다.
- 간격: 4px 단위. 레이블–입력란 8px, 같은 정보 묶음 12px, 카드 안 20px, 다른 섹션 사이 24px. 모바일 바깥 여백은 20px이다.
- 모서리: 입력란·버튼 8px, 선택 묶음 12px, 콘텐츠 카드 16px, 큰 대화상자 24px, 상태 배지 pill. 원형은 아바타·기분 그림처럼 형태 자체에 의미가 있을 때만 쓴다.
- 중첩: 상품 카드 16px − 안쪽 여백 8px = 이미지 8px. 세그먼트 12px − 여백 4px = 선택 항목 8px. 관련 토큰은 `radius-media`, `radius-segment`이다. 폼 필드는 독립 컨트롤이므로 카드의 동심 요소로 취급하지 않는다.
- 그림자: 최상위 콘텐츠 카드에 `card-shadow`만 사용한다. 입력란·중첩 패널에 그림자를 반복하지 않는다.

## 컴포넌트의 역할

| 역할 | 사용 | 피할 것 |
| --- | --- | --- |
| 저장·승인 등 동작 | `Button`, 주요 동작은 primary | 이동에 button 사용, 모든 동작을 primary로 표시 |
| 페이지 이동 | 일반 `Link`, 주요 CTA는 `LinkButton` | 링크에 `role="button"` 부여 |
| 페이지 제목 | `PageSection`의 h1 | 같은 화면에 페이지 제목 반복 |
| 빈 목록 | `EmptyState`와 필요한 다음 동작 하나 | 빈 목록을 오류 alert로 표시, 장식용 큰 아이콘 |
| 처리 결과 | `StatusMessage`, 오류만 alert | 평상시 안내를 성공·오류 메시지로 표시 |
| 기분 하나 선택 | `EmotionSelector`의 native radio | 독립적인 토글 버튼 여러 개 |
| 같은 목록 좌우 탐색 | 기존 `CardCarousel`, 위치·이전·다음 제공 | 상점을 다시 캐러셀로 변경 |
| 계정 정보·도움말 | 관련 위치의 details | 매번 보이는 긴 사용법 |

## 문구

제목과 핵심 값만으로 역할이 분명하면 부제를 넣지 않는다. 입력란에 이미 레이블이 있으면 반복 placeholder를 넣지 않는다. 계정 연결 승인, 공개 범위, 클로버 차감 등 결정에 영향을 주는 안내는 해당 위치에 유지한다. 검색 방식·꾸미기 설정처럼 가끔 필요한 내용은 details로 접는다.

## 검증

`npm run build`는 CSS 클래스 참조, 토큰·4px 간격 규칙, 타입과 번들을 검사한다. 캐릭터·상품 삽화·프로필 미술의 좌표는 레이아웃 간격 규칙의 예외이며, 일반 UI 여백으로 확장하지 않는다. 320·390·768·1280px에서 넘침·한글 줄바꿈·키보드 선택·선택 상태를 확인한다.
